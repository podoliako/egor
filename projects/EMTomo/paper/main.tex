\section{Introduction}
\label{sec:introduction}

Local-earthquake travel-time tomography uses picked seismic arrival times to estimate three-dimensional velocity structure and earthquake locations. Early work already formulated the inversion in terms of both source and medium parameters \parencite{aki1976}. An earthquake hypocenter is not an independently measured datum: its location is inferred from arrival times using an assumed velocity model, while velocity reconstruction in turn depends on the event locations \parencite{thurber1992,kissling1988}. Treating catalog hypocenters as fixed inputs can therefore propagate location errors and dependencies on the models and procedures used to construct the catalog, particularly when those assumptions or location uncertainties are not documented. This coupling motivates estimating earthquake locations and velocity structure together.

Travel-time tomography remains useful for constructing and refining local velocity models \parencite{fichtner2024seismic}. Such models can also provide starting points for waveform-based inversion, whose results may depend on the initial model \parencite{virieux2009}. There is therefore continued demand for practical methods that use arrival-time data to estimate three-dimensional structure without assuming accurately known earthquake locations.

Established joint-inversion methods iteratively update the velocity structure and an individual location estimate for each earthquake \parencite{thurber1983}. They differ in how those estimates are initialized: tomoDD uses initial event locations \parencite{zhang2003}, whereas LOTOS determines them from arrival times and station coordinates in a one-dimensional reference model before three-dimensional inversion \parencite{koulakov2009}. In these formulations, locations enter velocity updates as individual estimates rather than as weighted alternatives. Probabilistic methods address different parts of this problem. Event-location methods can characterize alternative hypocenters given a prescribed velocity model \parencite{lomax2000,smith2022}. Bayesian joint inversion has been demonstrated for both one-dimensional velocity structure \parencite{ryberg2019} and three-dimensional local-earthquake tomography using trans-dimensional Monte Carlo sampling \parencite{pianaagostinetti2015}; the latter jointly samples hypocenters and velocity structure without requiring catalog locations as starting coordinates. DeepGEM proposes generalized expectation--maximization for blind inversion \parencite{gao2021}, while a recent three-dimensional variational double-difference method quantifies uncertainty in the velocity structure \parencite{yang2025}. These approaches differ in their treatment of location uncertainty and computational strategy; joint probabilistic 3D inversion without catalog starting locations is therefore not unique to EMTomo.

Against this background, we ask a narrower practical question: under otherwise matched settings, how does replacing one best-fitting hypocenter with several weighted location hypotheses affect three-dimensional travel-time inversion? We present EMTomo, an iterative framework that alternates between locating events in the current velocity model and updating the model by regularized inversion. It requires arrival-time picks associated with individual events, station coordinates, and an initial velocity model defined on the inversion grid; the initial model may be one-dimensional or three-dimensional. The inversion uses one selected phase (P or S) at a time and does not require catalog hypocenter coordinates. EMTomo uses differences between arrivals at pairs of stations for the same event, which eliminate that event's origin time. This is distinct from tomoDD's double-difference formulation, which compares arrival times from pairs of events at common stations \parencite{zhang2003}. Candidate locations are selected from the within-event misfit and can contribute to the model update with weights. We compare single-location and multiple-hypothesis updates within EMTomo across a series of synthetic three-dimensional checkerboard tests, spherical anomalies, and a more natural tomography-derived velocity model, using both idealized and real event--station geometries. This within-method comparison isolates the effect of retaining multiple location hypotheses. We also use tomoDD as an established external reference to put reconstruction quality in the context of a widely used joint-inversion workflow, rather than to attribute differences between the two methods solely to the handling of location uncertainty. Both methods receive the same synthetic arrival-time picks, referenced to the earliest station arrival for each event; tomoDD additionally receives initial hypocenters obtained by perturbing the true synthetic locations, whereas EMTomo does not use initial event coordinates. Because the methods differ in their inputs, velocity parameterization, and interpolation, the comparison is intended to characterize their behavior in these specified settings rather than claim a universal resolution advantage.

  The travel time $\tauijk{n}$ from a candidate hypocenter cell $(i,j,k)$ to station $n$
  is a functional of the 3D slowness field $S(\mathbf{x})$, discretized into $L$ cells.
  The \emph{sensitivity matrix} $\mathbf{G}$ relates perturbations in slowness to
  perturbations in travel time:

  \begin{equation}
    G_{n\ell}^{\,ijk} \;=\; \frac{\partial \tauijk{n}}{\partial S_{\ell}},
    \label{eq:sensitivity}
  \end{equation}

  where $S_{\ell}$ is the slowness of cell $\ell$ and $G_{n\ell}^{\,ijk}$ equals the
  ray-path length through cell $\ell$ for the ray connecting $(i,j,k)$ to station $n$.

  \begin{algorithm}[t]
  \caption{EM-based 3D seismic tomography}
  \label{alg:em}
  \begin{algorithmic}[1]
    \Require Arrival times $\{t_{ni}\}$; initial slowness model $\svec^{(0)}$
    \Ensure  Updated slowness model $\svec^{*}$; hypocenter set $\{(i^*,j^*,k^*)_e\}$
    \State $k \leftarrow 0$
    \Repeat
      \State \textbf{E-step:} for each event $e$, evaluate $\Phi_{ijk}$ and locate
             $(i^*,j^*,k^*)_e \leftarrow \arg\min_{ijk}\,\Phi_{ijk}$
      \State \textbf{M-step:} assemble $\Gtil$ and $\rvec$;
             solve the regularized inverse problem for $\ds^{(k)}$;
             update $\svec^{(k+1)} \leftarrow \svec^{(k)} + \ds^{(k)}$
      \State $k \leftarrow k + 1$
    \Until{$\|\ds^{(k)}\| < \varepsilon$ \textbf{ or } $k = k_{\max}$}
    \State \Return $\svec^{(k)}$, hypocenter estimates
  \end{algorithmic}
  \end{algorithm}
