# Geysers: оценка пространственно отложенных событий, 17 ноября 2026

Очередь: `projects/EMTomo/runs/geysers_real_linear35_60_ball10_it15_20261117_105529`.
Численные результаты: `evaluation_pick20_seed42/summary.json` внутри очереди;
протокол и SHA256 кода/входов: `protocol.json`; прогнозы: `*_predictions.npz`.

## Протокол

Все 345 событий в шаре радиусом 1400 м вокруг локальной точки
(9500, 3000, 2500) м полностью исключались из инверсии скорости. Их 3813 пиков
разделены одинаково для всех моделей: 3054 для локализации и времени очага,
759 для независимой проверки предсказаний. По каждому событию отложено примерно
20% конечных пиков (округление, минимум один проверочный и пять для локализации),
seed=42. Стартовая и две финальные модели фиксированы; скорость не обновлялась.

Локализация: MAP, K50/dmin7, расчётная сетка 125 м, likelihood sigma
(relative=.01, absolute=.05 s, model=.02 s). Время очага оценивается только по
пикам локализации, с весами обратной дисперсии. Каталог не используется ни как
начальная точка, ни как ограничение поиска. Локализация не ограничивается шаром.
Внешние 4775 holdout-пиков не открываются.

Парный bootstrap по событиям, 5000 повторов, seed42: 95% интервалы изменения
проверочного RMSE относительно старта — soft [−20.43, −10.87] мс,
hard [−19.16, −6.47] мс. Для hard минус soft: [−0.81, +7.21] мс,
поэтому уверенно объявлять преимущество soft над hard нельзя.

Оба варианта улучшают предсказания относительно старта на этом разбиении.
Расстояние до каталога не является истинной ошибкой локализации; улучшение RMS
расстояния не означает улучшения всех квантилей: P90 здесь вырос.
На проекциях сохраняются отдельные удалённые и приграничные решения.
Это один пространственный блок и одно разбиение пиков; bootstrap условен на
данный блок и не доказывает переносимость на другие области.
