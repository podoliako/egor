# Графика, не включённая в текущую статью

Архив создан 17.11.2026 по фактическим `\\includegraphics` в `paper/main.tex` и подключённом `paper/results.tex`.

Здесь находятся 197 графических файлов, не используемых напрямую в текущей сборке: старые рисунки, варианты, PNG-превью и SVG-экспорты. Структура каталогов сохранена относительно прежнего `paper/figures/`. Файлы не удалялись и не перекодировались.

11 используемых PDF находятся в `paper/figures/used/`. Их список в порядке статьи: `paper/figures/used/README.md`.

`manifest.json` описывает все 208 перемещений: старый путь, новый путь, статус `used`/`unused` и SHA-256. Все контрольные суммы проверены после переноса. Пути указаны относительно корня EMTomo.

Данные и генераторы остались на прежних местах. Генераторы ещё могут сохранять изображения по старым путям; при дальнейшей подготовке рисунков нужно направлять окончательные PDF в `paper/figures/used/`.
