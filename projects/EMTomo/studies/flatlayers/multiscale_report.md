# hard-c1000, цикл 8 → hard-c500

Взята `iter_8/model.npy`: модель **после восьми полных обновлений**. Каждый километровый блок разделён на 2×2×2 блока 500 м без изменения скорости. Поле скорости на расчётной сетке 125 м совпало побитово.

Гипоцентры не переносились и не фиксировались: обычный hard-поиск, K=5, одна выбранная гипотеза. Выполнены все 12 циклов; lambda=0.5, coverage power=1, шаг ±2%, 52 станции, 1920 событий. Регуляризация к стартовой модели не добавлялась.

Для чистого сравнения использована исходная формула forward из сохранённых hard-c1000/c500, до последующей v2-правки внутренней среды сферы. Replay действует только внутри этого study-процесса; production-код не откатывался. Версия записана в meta.json.

## Результаты на одной и той же сетке оценки 500 м

| Цикл 500 м | Вся модель: исходный / multiscale, м/с | Верхние 500 м: исходный / multiscale, м/с |
|---:|---:|---:|
| 0 | 140.02 / 137.27 | 0.63 / 33.54 |
| 1 | 133.03 / 137.37 | 28.65 / 36.36 |
| 2 | 129.20 / 140.20 | 47.85 / 41.05 |
| 4 | 129.72 / 146.23 | 72.45 / 50.21 |
| 8 | 143.34 / 157.57 | 100.96 / 65.70 |
| 12 | 158.13 / 170.44 | 118.92 / 77.29 |

**Верхний слой лучше, модель в целом хуже.** Финальная RMS верхних 500 м уменьшается с 118.92 до 77.29 м/с (35.0%). Общая RMS увеличивается с 158.13 до 170.44 м/с.

При этом верх не становится правильным: его ошибка растёт с 33.54 до 77.29 м/с за 12 обновлений на сетке 500 м.

Основное ухудшение относительно исходного hard-c500 — не в верхних 500 м. Например, финальная RMS на глубине 1.5–2 км: 247.8 против 155.6 м/с; 3–3.5 км: 252.3 против 185.5 м/с.

Локализация: медиана ошибки первого/последнего E-шага multiscale — 107.8 / 117.5 м; для исходного hard-c500 — 143.3 / 95.5 м.

Невязка последнего E-шага почти одинакова: 20.718 / 20.724 мс (исходный / multiscale). Это значения **до последнего скоростного обновления**, не повторная локализация в final_model.

RMS 83.56 м/с у исходного hard-c1000 цикла 8 нельзя прямо сравнивать с 137.27 м/с у перенесённой модели: эталон усредняется на разных ячейках. Сам перенос расчётное поле не изменяет; все числа таблицы выше рассчитаны относительно одного эталона на сетке 500 м.
