# Поисковый тест Hard-K против Soft-K (2026-10-08)

**Задача:** специально найти режим, где несколько гипотез локализации полезнее
жёсткого выбора одной из **того же** набора гипотез. Это поисковый пример на
одной реализации шума, не оценка среднего преимущества и не основание для
утверждения об универсальной сходимости. Все тесты с неудачными настройками
сохранены ниже. Выбор параметров и лучшей итерации после просмотра истины
делает максимум заведомо оптимистичным.

## Данные

Из корня репозитория `egor`:

```sh
python -m projects.forward_modeling.hypocentre_ambiguity_example
python -m projects.forward_modeling ambiguity24x18x12_8st_80ev_seed17 \
  --refinement 12 --check-convergence --noise \
  --noise-relative-sigma 0 --noise-absolute-sigma-s 0.12 --noise-seed 17
```

Рецепт генератора также создаёт вариант `--homogeneous` под отдельным ID;
запускать его можно с теми же параметрами шума, но он **не** является примером
восстановления неоднородности. Входы уже созданы локально и не перезаписываются;
обе директории `experiments/input`, `experiments/output` игнорируются Git.
Основной сценарий: 24×18×12 км, 6-километровые кубы с Vp 4500/5500 м/с,
8 поверхностных станций (4×2), 80 источников (4×4×5), глубина от 2 км,
не совпадающая с центрами скоростных ячеек. Отдельный `forward_modeling`
решает PyKonal, а EMTomo инвертирует с `skfmm`. Для независимого FMM
`refinement=12→24` дал RMS 0.0171 с и максимум 0.0944 с разницы относительных
времён при σ пиков 0.12 с. Это *индикатор сходимости*, не оценка абсолютной
ошибки приближённой геометрии станций в инверсии.

## Честная пара

Из `projects/EMTomo`:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python studies/compare_hypocentres.py \
  ambiguity24x18x12_8st_80ev_seed17 --cell-size-m 3000 \
  --subdivision 6 --weights-top-n 8 --weights-min-distance 6 \
  --cycles 10 --workers 4 --temperature 1 --weight-model-sigma-s 0.12 \
  --lambda-reg 0.05 --coverage-damping-power 1 \
  --max-velocity-step-fraction 0.01
```

Обе ветви получают **одни** станционные времена, поле Vp=5000 м/с,
кандидатов K=8, тот же поиск и уточнение, идентичную регуляризацию. Различие
только в `candidate_mode`: `hard` берёт MAP из этих восьми, `soft` суммирует
их взвешенные нормальные уравнения. Инверсионная сетка (8,6,4), сторона
3 км; поисковая — 0.5 км. `weights_min_distance=6` означает 3 км между
центрами отобранных ячеек по метрике Чебышёва, **не** гарантирует такое же
расстояние уточнённых координат. Параметр `weight_model_sigma_s` —
предполагаемое расхождение модели, подобранный для исследования; его нельзя
называть измеренной точностью прямого решателя. Скрипт проверяет совпадение
метаданных и стартовой модели, выдаёт RMSE по истинной скорости после каждого
полного шага и JSON-отчёт в игнорируемый `runs/`.

## Что получилось (одна реализация, exploratory)

В таблице положительная разность означает меньшую RMSE у `soft`.

| Параметры (`K=8`, σ пиков=0.12 с) | Цикл и RMSE `soft`/`hard`, м/с | Выигрыш `soft` | Ограничение |
| --- | --- | --- | --- |
| `dmin=4`, σ модели=0.30 с, λ=0.1, шаг≤2%, 5 циклов | цикл 5: 472.1 / 479.6 | 7.5 м/с (1.57%) | эффективное K≈7.66: веса почти равномерны |
| `dmin=6`, σ модели=0.12 с, λ=0.05, шаг≤3%, 10 циклов | цикл 4: 485.5 / 502.5 | 17.0 м/с (3.39%) | **цикл выбран post hoc**; к циклу 10 обе модели хуже стартовой (615.4 / 661.5 м/с; видимый выигрыш 46.1 м/с — артефакт более медленной деградации) |
| `dmin=6`, σ модели=0.12 с, λ=0.05, шаг≤1%, 10 циклов | цикл 9: 496.6 / 509.9 | 13.3 м/с (2.61%) | цикл выбран post hoc; на заранее заданном цикле 10: 504.4 / 519.4, обе хуже стартовой |
| Однородная истина 5000 м/с, σ модели=0.12 с, `dmin=6`, λ=0.05, шаг≤1%, 5 циклов | цикл 5: 174.2 / 161.0 | **−13.2 м/с (−8.21%)** | при истинной стартовой модели `soft` создаёт **больше** ложной структуры |

Стартовая RMSE в шахматной истине 500 м/с; в однородной — 0 м/с.
Во втором и третьем вариантах эффективное K в начале ≈3.2, при уточнённых
гипоцентрах с отличающимися лучами. Диагностика первых 80 событий третьего
варианта после инверсии: среднее расстояние MAP до истинного гипоцентра
2.38 км, ближайшего из восьми — 1.20 км; в 77.5% событий один из восьми
лежит не далее 1.5 км от истины. Координаты истины здесь использованы
**только для оценки**, не для поиска/назначения весов. Это иллюстрирует
потенциальный механизм выигрыша, но не гарантирует пользу для скоростей.
**Наибольшая наблюдаемая разница** 46.1
м/с (6.97%) не означает выигрыш в реконструкции: обе модели тогда
деградировали. Наибольшая *в этом поиске* разница при `soft` лучше стартовой
и `hard` хуже стартовой — 17.0 м/с (3.39%) на четвёртом цикле. По данным
пока нельзя судить о максимальном *возможном* преимуществе метода.

остановки и область оценки *до* новых данных, повторить на независимых шумовых
реализациях и проверить отложенные приходы. Однородный отрицательный контроль
нужно включать в оценку, а не исключать как неудобный.

## Продолжение: 128 Sobol-событий, заранее заданные 8 циклов

Та же область, истина и 8 станций; вместо регулярной сетки событий — 128
Sobol-событий. Данные для seed 23/24/25 созданы независимо в
`forward_modeling` (PyKonal, refinement 12, проверка 12→24; независимый шум
абсолютных пиков σ=0.12 с). Поисковую настройку выбрали после просмотра seed
23; **seed 24 и 25 не использовали для её настройки**. Для каждого seed из
корня репозитория:

```sh
python -m projects.forward_modeling.generator ambiguity24x18x12_8st_128ev_sobol_seed25 --lengths-km 24 18 12 --blocks 4 3 2 --velocities-m-s 4500 5500 --surface-stations 4 2 --events 128 --min-depth-km 2 --bottom-bias 0 --seed 25
python -m projects.forward_modeling ambiguity24x18x12_8st_128ev_sobol_seed25 --refinement 12 --check-convergence --noise --noise-relative-sigma 0 --noise-absolute-sigma-s 0.12 --noise-seed 25
```

Из `projects/EMTomo` (заменять **везде** ID и seed на 23/24/25):

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python studies/compare_hypocentres.py ambiguity24x18x12_8st_128ev_sobol_seed25 --cell-size-m 3000 --subdivision 6 --weights-top-n 8 --weights-min-distance 6 --cycles 8 --workers 4 --temperature 1 --weight-model-sigma-s 0.12 --lambda-reg 0.1 --coverage-damping-power 1.5 --smoothness-reg 0.2 --max-velocity-step-fraction 0.01
```

RMSE скорости после фиксированного цикла 8 (старт 500 м/с):

| Seed | Soft, м/с | Hard, м/с | Выигрыш soft, м/с | JSON в `runs/` |
| --- | ---: | ---: | ---: | --- |
| 23 (поисковый) | 428.297 | 463.229 | 34.932 | `hypocentre_comparison_9df6fd5ca77848858f62b8fbf3694025.json` |
| 24 (повтор) | 435.032 | 448.671 | 13.639 | `hypocentre_comparison_b8e1950f2c7d43139e28cecd56cee575.json` |
| 25 (повтор) | 428.274 | 445.190 | 16.916 | `hypocentre_comparison_80532e71a29c49ffb18e64438189b1c1.json` |

На seed 24 `soft` убывает до шага 8, но при продолжении до шага 16 RMSE
растёт до 472.974 м/с (`hard`: 489.507); отдельный диагностический отчёт:
`runs/hypocentre_comparison_d0d137b8785949d2bb3ce24ada0c7e1d.json`.
Это **улучшение при ранней остановке**, а не доказательство сходимости EM к
истине. В seed 24/25 меняются гипоцентры и шум, но не истинное поле скоростей
и схема станций; следующее независимое испытание — иная геометрия/истина и
отложенные пики. Сгущение прямой сетки 12→24 дало RMS различия относительных
времён ≈0.020 с для seed 24/25 (не гарантия абсолютной точности).
