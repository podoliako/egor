# Использованы ли те же P-пики, что в нашем real-pick эксперименте?

Проверено 2026-11-08 для скачанной **GJI 2021 Vp**, DOI
[10.1093/gji/ggab017](https://doi.org/10.1093/gji/ggab017), не для JGR 2022.

**Нет: наборы входных наблюдений различаются.** Общий регион, архив NCEDC и
частично общие события не означают совпадения P-arrival observations.

## Источники

- Текст статьи, §4.1 «DD earthquake relocation and Vp tomography»:
  https://par.nsf.gov/biblio/10316216/media/xml
- Страница рукописи NSF PAR: https://par.nsf.gov/biblio/10316216
- Каталог авторов: `Geysers_EQReloc_Guo-Thurber2021GJI.CSV`, Zenodo 4470253.
  Скачан без изменений; размер и MD5 проверены по API Zenodo.
- Наша подготовка: `../geysers_2011/real_experiment_v1/`, описание
  `../../studies/geysers_real_picks/README.md`.

Текстовая конвертация NSF содержит пропуски, в частности обрыв предложения об
исходном отборе событий в начале §4. Ниже не восстанавливаем отсутствующий текст
предположениями. Временной диапазон опубликованных релокаций проверен по CSV.

Цитата §4.1 о P arrivals:

> We began by repicking P-wave first arrivals in the waveform time windows around
> catalogue picks using an automatic seismic arrival picking code [...], which
> is based on the Akaike Information Criteria method [...].

Цитата о наблюдениях Vp-инверсии:

> Finally, we obtained 6222 632 catalogue differential times for 1238 subcell
> events and 361 752 WCC differential times for 1212 subcell events, which are
> used for the final DD tomography along with the 74 652 absolute times for
> 2937 events.

Приведённые differential counts — числа наблюдений, не числа пар событий;
1238 и 1212 subcell events не следует складывать с 2937.
WCC — отдельные дифференциальные наблюдения, не доказательство коррекции каждого
absolute pick. Данные Qp (t* и dt*) не включены в эту таблицу.

## Проверка пересечения событий по опубликованному каталогу

Каталог авторов содержит 2934 события от **2011-01-01 00:58:13.14** до
**2011-12-31 22:27:19.08**. В наш интервал `[2011-04-01, 2011-04-21)`
попадают **239** опубликованных событий.

**В CSV авторов нет event ID**, поэтому выполнено только кандидатное
сопоставление с нашим исходным каталогом 3776 событий:

1. Выбран ближайший по origin time наш event.
2. Требуется разница времени не больше **0.5 с**.
3. Требуется горизонтальное расстояние не больше **2 км** между опубликованной
   релокацией и нашей каталожной позицией; глубина в критерий не включалась.
4. Проверено отсутствие второго нашего события в том же временном допуске.

Получены **236 кандидатов на общие события**, все — разные наши ID, все входят
в выборку 3471 train events. Неоднозначных совпадений по временному допуску нет.
Максимальная разница origin time среди кандидатов **0.31 с**, максимальное
горизонтальное расстояние **1.1682 км**. Три оставшихся опубликованных события
в нашем временном интервале не прошли критерий. Порог не доказывает их отсутствия
из полного NCEDC-каталога: сравнивалась только наша пространственно отобранная
выборка.

Это примерно **6.8% наших train events**, но **не доля общих пиков**.
Времена origin в каталоге релокаций могут отличаться от исходного каталога.
Опубликованный список релокаций (2934) также не тождественен списку входов
Vp-инверсии (2937 по статье). Поэтому 236 — результат сопоставления доступных
каталогов, не точный event-ID join исходных входов инверсии.

Машиночитаемый аудит: `input_data_comparison.json`, список кандидатов и
непрошедших ближайших соответствий: `input_data_event_candidates.csv`.

## Что нельзя подтвердить

В скачанном наборе нет самих авторских AIC P picks, station list и WCC times.
Сравнение UTC каждого прихода с нашими train/holdout наблюдениями выполнить
нельзя. Нельзя утверждать ни полное тождество, ни полную независимость входов.

**Практический вывод:** модель полезна как внешняя опубликованная реконструкция
для геологического сравнения, но не как truth и не как результат на тех же
самых P-пиках. При потенциальном использовании её как начальной модели нельзя
считать нашу holdout-проверку строго независимой без проверки исходных
авторских наблюдений.
